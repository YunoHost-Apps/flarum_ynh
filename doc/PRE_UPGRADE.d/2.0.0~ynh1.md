This update will migrate your Flarum instance to Flarum v2.

**TL;DR: you need to install the Dex app before proceeding with the update. You need properly signed certificates.**

Long version: Behind the scene, this update required us to upgrade the Flarum LDAP extension, which was initially written for this YunoHost app. Due to volunteer time constraints, it is no longer sustainable to maintain this extension.

Since YunoHost will at some point be made compatible with OAuth or OIDC, we are now moving to an OIDC extension. The migration should be almost seamless: the login link disappears in favor of a YunoHost button in the Flarum standard login modal.

The selected OIDC provider is Dex, packaged as an app for YunoHost.
You need to install Dex before proceeding with this Flarum upgrade.
The Dex app requires properly signed certificates.

You may tweak the wording, icon, and color of the button in the OIDC extension settings.
